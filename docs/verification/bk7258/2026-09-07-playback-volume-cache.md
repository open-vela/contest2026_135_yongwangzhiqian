# 播放音量缓存验证

2026-09-07：播放前音量入口改用偏好所有者维护的最后确认值，不再每轮访问 SD NAND。
第一次使用仍需读取数据库；完整偏好查询会刷新缓存，成功提交音量后更新缓存。
在取得介质前被拒绝的设置不改变旧值；后端读取、提交或清理发生不确定错误时使缓存
失效。MSC 外部编辑需显式 `bkvoice prefs` 刷新或重启后加载，不自动影响当前会话。

偏好层同一 mutex 覆盖存储操作和缓存发布。挂载 helper 的原锁移至该所有者，避免
卸载后解锁与缓存发布之间发生旧读取覆盖新设置的竞态；没有并行的第二配置 owner。
缓存是可丢弃运行时状态，不是另一个持久后端。

```sh
make -C tests/host/bk7258 run-preferences run-voice-turn-volume run-voice-turn-audio
```

均通过。缓存测试覆盖首次读取、已有缓存时介质 EBUSY 且零存储访问、忙介质写入被拒
后旧值保留、成功设置更新、失败后强制重读、外部编辑仅在显式查询后生效及空指针。
播放生命周期的原失败清理和量化边界测试继续通过；这些是主机测试。

`bk7258_preferences_playback_volume`；AP 裸二进制 856768 字节，SHA-256：
